# AuroraLab

An interactive science & art studio built in pure Java (Swing), with no external libraries.

## Features

- **Galaxy Forge:** real-time N-body gravity simulation. Click to spawn a galaxy, right-click to drop a black hole, or trigger a galaxy collision.
- **Fractal Voyager:** multi-threaded Mandelbrot and Julia set explorer with smooth colouring, zoom and animated colour palettes.
- **Life Lab:** Conway's Game of Life on a wrapping grid, with a Gosper glider gun and mouse drawing.
- Save a PNG screenshot of any tab from the File menu.

## How to run

Requires JDK 17 or newer.

    javac AuroraLab.java
    java AuroraLab

## Concepts used

Java Swing, event handling, timers, parallel streams, BufferedImage, numerical simulation, cellular automata.
